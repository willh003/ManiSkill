# ICL student code layout (`examples/baselines/ppo/`)

- `icl_tasks.py`: one class per hidden-variable task (`PushTTask`, `PickBiasTask`, `PegTask`, `RotTask`; registry `TASKS`). The interface is in the module docstring: `sample`, `reset_options`, `student_obs`, `expert_obs`, `prior_obs`, `final_error`, `metrics`. Add a task by writing a class and registering it.
- `icl_episodic.py`: DAgger loop, transformer student (`ICLPolicy`), `rollout` (modes expert / prior_expert / scripted / student), `collect_task_episodes`, `collect_scripted_episodes` (`--ctx-policies`: first m episodes by PPO checkpoints), eval + controls (`shuf_y`, `no_y`, `no_ctx`). Feedback kinds: `final_error`, `success`, `hints`, and for the peg task `language` (templated text command from the final error, `command_tokens` in `icl_tasks.py`, fed as word tokens through a from-scratch embedding) and `language_pretrained` (same command text embedded by a frozen sentence-transformers model, `--text-encoder`, one feedback token) and `language_tokens` (the command text through a frozen flan-t5-small encoder, `--token-encoder`: one LM feature vector per word piece, 36 per episode, stored fp16 with a mask channel in the ctx feedback buffer, LayerNorm + linear into the context, no hand-built vocabulary); the pretrained kinds need `uv pip install sentence-transformers` and the model in `$HF_HOME`=gscratch/will/hf_cache on klone, offline on compute nodes).
- `run_logging.py`: run dir layout (`logs/runs/<name>/`: config, metrics.jsonl, results.json, checkpoints, tb).
- `plot_icl.py`: success_once vs h for any set of `icl-*` runs, optional controls panel. `plot_ppo_curves.py`: PPO eval curves from tensorboard.
- `ppo.py`, `ppo_fast.py`: expert training (same Agent state dict). `slurm/expert_*.sbatch`: expert recipes; `slurm/icl.sbatch`: generic student job (usage in its header).
- Envs: `mani_skill/envs/tasks/tabletop/{push_t_goal,pick_cube_bias,peg_insertion_side_bias}.py`, `dexterity/rotate_dir_hidden.py` (the allegro expert did not learn yet, see the rotation attempt in the experiments).
